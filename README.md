## 🚀 Produtos e SaaS próprios

### 💰 Alpha Cash 2.0 — Análise financeira com IA
> Status: **em produção** · Tipo: micro-SaaS multi-tenant · Modelo: freemium + PIX

Sistema completo de finanças pessoais que importa extratos CSV/PDF dos principais bancos brasileiros (**Nubank · Banco do Brasil · Caixa · Inter · PicPay · Pluxee**) e gera análise inteligente de gastos via IA, incluindo feature **DeepDive** pra investigação contextual de transações.

**Highlights técnicos:**
- Arquitetura unificada (Fastify → Next.js API Routes pra deploy único na Vercel)
- Análise de extratos com Gemini AI + cache em Upstash Redis
- Mobile-first, SEO/OG otimizado, doação via PIX integrada
- Página de privacidade + FAQ humanizado pra reduzir objeções de confiança

`Next.js App Router` `TypeScript` `Tailwind` `Supabase` `Gemini AI` `Upstash Redis` `Vercel`
