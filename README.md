## Projetos em destaque

### Alpha Cash 2.0 — análise financeira com IA

<!-- TODO: adicionar link do produto em produção -->

Micro-SaaS de finanças pessoais que importa extratos CSV/PDF de bancos brasileiros (Nubank, Banco do Brasil, Caixa, Inter, PicPay, Pluxee) e gera análise de gastos com IA. Inclui o **DeepDive**, para investigar transações em contexto.

- Backend migrado de Fastify para Next.js API Routes — um único deploy na Vercel
- Análise de extratos com Gemini e cache em Upstash Redis
- Multi-tenant com Supabase (auth + RLS), mobile-first

`Next.js` `TypeScript` `Tailwind` `Supabase` `Gemini` `Upstash Redis` `Vercel`

`Next.js` `TypeScript` `Supabase` `shadcn/ui`

### [Monitor de Atendimentos CRM](https://github.com/thiago536/Monitor-de-atendimentos-CRM)

Monitoramento de atendimentos em três partes: extensão Chrome (captura via MutationObserver), API Node.js e dashboard com gamificação de equipe, mapa de clientes e previsão de picos de demanda.
